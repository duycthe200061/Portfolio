# Chu Thanh Duy - Personal Portfolio Website

A modern, clean, responsive single-page frontend portfolio created for **Chu Thanh Duy** (Software Engineering Student at FPT University). Built using pure **HTML5, CSS3, and Vanilla JavaScript**.

---

## 📌 Project Overview

This portfolio is styled in a **Dark Navy Blue & Cyan Accent** theme, specifically tailored for a Software Engineering internship candidate. All personal data, education history, skills, software projects, extracurricular activities, and certifications are sourced strictly from Chu Thanh Duy's CV.

1. **Hero / Home:** Introduction, tagline, quick pills (GPA, IELTS 7.5, Location), and profile photo placeholder.
2. **About Me:** Core focus on Java development, system design (UML/SRS/SDD), and teamwork.
3. **Skills & Knowledges:** Structured tags for Java, Web Frontend (HTML/CSS/JS/JSP/Servlet), Database (SQL Server), Tools (Git/GitHub/GitLab), and Languages.
4. **Featured Projects:**

   - Includes category filtering and detail modal views.
5. **Activities (Extracurricular):** Media Team Member for the *"Khi Stress Khong Len Tieng"* student mental health support project.
6. **Education:** FPT University (Software Engineering, GPA 3.2/4.0, 100% Highschool Scholarship).
7. **Certifications:** IELTS Academic 7.5 & Coursera Software Engineering certificates (UML, Testing, Project Management).
8. **Contact:** Interactive contact form & contact details.

## 🚀 How to Run & Customize

1. **View locally:** Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari).
2. **Replace Profile Photo:**
   - Place your real portrait image inside the `images/` directory.
   - Name it `profile.jpg` (or update the filename in `index.html` at line ~66).
3. **Hosting:**
   - Upload this repository to **GitHub** and enable **GitHub Pages**, or deploy directly via **Vercel** / **Netlify** for free hosting.
